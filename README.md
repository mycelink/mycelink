# mycelink

Mycelink community hub for mycelink.eco.

One free home for four crypto tools: TradingView, DexScreener, CoinMarketCap and Checkonchain.

## What is here

- `index.html` — the welcome page
- `app.html` — the dashboard, with the four tools as tabs
- `css/style.css` — the look (colours come from the Mycelink logo)
- `js/config.js` — settings: social links and what each tool shows first
- `js/app.js` — how the dashboard works
- `assets/` — the logo

## Changing the social links

Open `js/config.js` and paste each full link between the quotes.
